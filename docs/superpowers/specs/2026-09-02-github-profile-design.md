# GitHub profile design

## Goal

Create a concise GitHub profile for a general development club application. The profile should show both product-building ability and technical depth without relying on decorative statistics or unverified claims.

## Structure

1. Short Korean introduction focused on building usable products and solving implementation problems.
2. Two featured project cards in the same format: title, cover-image placeholder, stack, short description, key contributions, team size, responsibility, repository link, and optional demo-video link.
3. Featured projects:
   - RestructuringHome: an interactive room-plan and furniture-editing mobile app.
   - 3rd-person combat futsal game: a Unity multiplayer game combining football and combat.
4. A compact technology section listing only technologies used by the featured work.
5. A contact link to the GitHub account.

## Content rules

- Use accurate, readable Korean and established repository URLs.
- State that the game is at MVP stage; do not imply two-client or Internet P2P validation beyond what is demonstrable.
- Keep `담당` phrased as the owner's implementation scope, avoiding claims about the other teammate's work.
- Leave an explicit image and demo-video insertion point rather than inventing assets or URLs.

## Verification

- The repository name exactly matches the account name, so GitHub renders it on the profile.
- Rendered Markdown has working links for both repositories and no broken section hierarchy.
- The profile repository is public and its default branch contains `README.md`.
